# Build Bandits

**Digital workshop. Build. Ship. Repeat.**

We turn ideas into practical tools for everyday use: apps, web apps and scripts that save you time. Success is measured in the time you save, not in the time we spent building.

## How we work

- **Build**: mobile apps, web apps, scripts. The right tool to solve the problem or meet a need.
- **Ship**: we build and release fast. Better in the hands of the people who use it than idle in a repository.
- **Repeat**: we iterate. Every release is a starting point, not the finish line.
- **Support**: you'll find us right here. We keep shipping updates and taking care of maintenance.

## Get in touch

Got an idea that deserves to exist? [Propose it on buildbandits.com](https://buildbandits.com/en/#proponi) or write to [hello@buildbandits.com](mailto:hello@buildbandits.com).

Found a bug or have a feature request for an open-source project? Open an issue in its repository. Security vulnerabilities go through GitHub's private vulnerability reporting (**Security → Report a vulnerability**), never through public issues.
